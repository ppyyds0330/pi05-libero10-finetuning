# Historical pi05_base Rollout Videos

English | [简体中文](README.zh-CN.md)

This folder contains the ten original `pi05_base` LIBERO_10 videos, all labeled failure (0/10).

The MP4 bytes match the archived SHA256 records. The files were not re-encoded and the evaluation was not rerun.

See [per-task labels](../../results/pi05_base_task_results.csv) and the [historical summary and file hashes](../../results/pi05_base_summary.json).

The full original evaluation log and exact inference settings are not preserved in these artifacts. The run used a LIBERO interface and borrowed LIBERO normalization, so it should not be described as a strict target-data-free zero-shot benchmark.
